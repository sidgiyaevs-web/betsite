# LIVEZONE — Live Sports Simulator

Полный демонстрационный сайт ставок на спорт (не настоящая букмекерская контора).

## Возможности

- ⚽ Футбол, 🏒 Хоккей, 🎾 Теннис, 🥊 UFC/MMA, 🎮 Киберспорт
- Живая симуляция матчей: счёт, минута, события (голы, раунды)
- Коэффициенты обновляются в реальном времени (плюс шум)
- Регистрация / вход, баланс
- Ежедневная игровая выплата: **+200 000 ₽ в день**
- Купон: одиночные и экспрессы, авторасчёт выигрыша
- История ставок, статистика, результаты

## Запуск

Просто откройте [index.html](index.html) — всё работает в браузере без сервера
(данные хранятся в localStorage).

## Структура

```
index.html        — разметка
css/styles.css    — стили (тёмная тема)
js/data.js        — спорты, лиги, команды, генерация матчей, кэфы
js/storage.js     — аккаунты, баланс, ставки, автопополнение
js/engine.js      — движок симуляции LIVE
js/ui.js          — интерфейс, купон, профиль, результаты
js/main.js        — точка входа
```

> Демонстрационный проект. Не является букмекерской конторой и не принимает реальные ставки.
